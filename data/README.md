# Dataset Information

The trained ML model in `ml/model.json` was trained on the **PhiUSIIL Phishing URL Dataset**.
- **Citation**: Prasad, A., & Chandra, S. (2023). *PhiUSIIL Phishing URL Dataset*. UCI Machine Learning Repository.
- **Source**: Available on the UCI Machine Learning Repository or Kaggle.
- Raw CSV files (>50MB) and zip archives are excluded from Git tracking via `.gitignore` to keep the extension repository lightweight.
